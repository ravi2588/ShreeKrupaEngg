## ?? TROUBLESHOOTING

### If Page Won't Load
- Ensure dotnet run is still active
- Check browser shows http (not https)
- Try localhost:5085 exactly
- Press Ctrl+F5 to hard refresh

### If Images Don't Show
- Images are from Unsplash CDN
- Check internet connection
- Try refreshing page (Ctrl+F5)
- Images may take few seconds to load

### If Navigation Doesn't Work
- Click exact menu items
- Wait for page to load
- Check URL in address bar
- Try refreshing browser

### If Form Doesn't Submit
- Fill all required fields (*)
- Check for validation messages
- Try simple input first
- Check browser console for errors
